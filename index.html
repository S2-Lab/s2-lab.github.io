Secure Software Lab (S2 Lab)

Our lab is dedicated to enhancing the security of software and AI systems through vulnerability detection and the enforcement of secure execution.

Our recent research focuses on the following areas:

1

Open-Source Software Security

identifying vulnerabilities in open-source software

2

Rust Security

improving the security of Rust compiler and applications

3

Physical AI Security

identifying vulnerabilities in physical AI, including robots, autonomous vehicles, and drones

4

AI Agent Security

developing runtime enforcement approaches to prevent AI agent misbehavior

5

AI Model Security & Privacy

identifying and mitigating security and privacy threats in AI models, including jailbreaks, backdoors, and membership inference attacks

We are always looking for motivated undergraduate and graduate students, as well as postdoctoral researchers. If you are interested in working with us, please send an email to Yuseok Jeon (ys_jeon@korea.ac.kr).
